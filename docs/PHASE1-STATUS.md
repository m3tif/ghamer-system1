# حالة Phase 1

## ✅ مكتمل ومُختبَر
- Schema كامل لقاعدة البيانات للمرحلة الأولى + Migrations + بيانات الأدوار والصلاحيات (12 دورًا و46 صلاحية).
- تسجيل الدخول (Argon2id)، جلسات قابلة للإلغاء، قفل الحساب، تغيير كلمة المرور الإلزامي، TOTP MFA بسر مشفّر.
- RLS على كل الجداول؛ لا DELETE لأي دور؛ المصدر الأصلي والمسجِّل الأصلي لا يتغيران إلا عبر دالة إدارية بسبب مكتوب.
- منع التكرار (هاتف، رقم بديل، واتساب، متجر) على مستوى الواجهة والـ Backend وقاعدة البيانات، مع اختبار 24 تسجيلًا متزامنًا.
- طلب مراجعة الملكية، ونقل الملكية بسجل كامل.
- الاجتماعات (حجز، تأكيد، إعادة جدولة على نفس السجل، إلغاء، لم يحضر، إعادة إسناد) بلا احتساب مزدوج.
- التارجت للتيلي سيلز على الاجتماعات المنعقدة فعليًا، ومقاييس التحويل والعقود.
- خط المبيعات (14 مرحلة)، البريف، المتابعات بسبب إلزامي، سجل المراحل، إخفاء الصفقات عن Tele Sales.
- Tele Sales ترى نتيجة الاجتماع والصفقة فقط عبر دالة مخصصة.
- Audit Log لا يقبل التعديل. إشعارات داخلية بلا تكرار. مهمة يومية آمنة ضد التكرار.
- لوحات: Tele Sales، Sales، مدير كل فريق، المدير العام. 46 اختبارًا ناجحًا. الـ Build ناجح.
- اختبار HTTP على النسخة المبنية: صلاحيات الصفحات لعشرة أدوار، وعزل العملاء والصفقات بين الموظفين.

## ⚠️ لم يُنجَز أو لم يُتحقق منه بعد
- **لم تُفحص الواجهة بصريًا** (لا يوجد متصفح في بيئة التطوير). افحص الشاشات على الجوال والكمبيوتر وأبلغنا بأي ملاحظات.
- **لم تُختبر Server Actions بالنقر في متصفح** (اختُبرت منطقيًا عبر الدوال والـ SQL وعبر عرض الصفحات). يلزم اختبار قبول يدوي للرحلة كاملة.
- لم يُنشر على Supabase/Vercel فعليًا (لا وصول من هنا). الدليل جاهز لكن لم يُجرَّب على حسابك.
- Kanban للعرض والفتح فقط (بدون سحب وإفلات). تغيير المرحلة من صفحة الصفقة.
- تقويم المتابعات: عرض مجمّع حسب اليوم، وليس شبكة شهرية.
- لا إشعارات بريد أو واتساب (داخل النظام فقط). لا رفع ملفات (Phase 2/3). لا تصدير Excel/PDF (Phase 4).
- لا تقييد IP للمحاولات (القفل على مستوى الحساب فقط). CSP يسمح `unsafe-inline` لسكربتات Next.
- لم تُحمَّل بيانات اختبار ضغط. لم يُجرَّب استرجاع نسخة احتياطية.
- جداول المراحل 2–4 (عروض، عقود، دفعات، عمولات، مشاريع، مهام، تكاليف) **لم تُنشأ بعد**؛ سيضاف لها Migration في بداية كل مرحلة. التصميم يستوعبها (انظر وثيقة المعمارية).
