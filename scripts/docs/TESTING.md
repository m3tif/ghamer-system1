# الاختبارات
```bash
# PostgreSQL محلي (مثال Ubuntu): sudo apt install postgresql
# مستخدم postgres بكلمة مرور postgres على localhost:5432، أو اضبط TEST_PG_ADMIN=postgres://user:pass@host:5432
npm test
```
كل ملف اختبار ينشئ قاعدة بيانات جديدة ويطبّق الـ Migrations ثم يختبر عبر مستخدم التطبيق المحدود `ghamer_app` (نفس ما يعمل في الإنتاج).

| الملف | ما يغطيه |
|---|---|
| `tests/normalize.test.ts` | توحيد الأرقام (05… و+966…) وروابط المتاجر |
| `tests/db-security.test.ts` | منع التكرار حتى مع 24 طلبًا متزامنًا، عزل البيانات، منع الحذف، حماية المصدر الأصلي، الاجتماعات والتارجت، الصفقات، التدقيق، المهام المجدولة |
| `tests/auth-db.test.ts` | قفل الحساب، الجلسات، إنشاء الموظفين، تغيير كلمة المرور، التشفير والمصادقة الثنائية |
